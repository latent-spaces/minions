# Repository tools

Keep development utilities outside the production application. Each tool has its own entry point and README.

| Folder | Purpose |
| --- | --- |
| [setup](setup/README.md) | One-command standalone engine setup with this computer connected. |
| [benchmarks](benchmarks/README.md) | Bounded benchmark and capacity studies. |

A local preview tool must not add a production app route or its own copy of a production template. Reuse the canonical source and shared presentation primitives where appropriate.
