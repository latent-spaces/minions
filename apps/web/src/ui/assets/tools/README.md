# Official product SVG marks

These standalone SVG files are copied byte-for-byte from vendor-published VS Code
extensions, retrieved 28 October 2026. They replace the earlier Lobe Icons copies.
Original paths, pinned versions and SHA-256 hashes are in [sources.json](sources.json).
No vector path, fill or viewBox is redrawn or changed.

- `claude.svg`: Anthropic Claude Code 2.1.312, `resources/claude-logo.svg`,
  explicitly selected for Claude Code commands and the sidebar in its manifest.
  [Official extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code),
  [Claude Code documentation](https://code.claude.com/docs/en/overview).
- `codex.svg`: OpenAI Codex extension 26.1021.22027,
  `webview/assets/codex_new-f14177b03534.svg`.
  [Official extension](https://marketplace.visualstudio.com/items?itemName=OpenAI.chatgpt).
- `chatgpt.svg`: the same OpenAI extension, `resources/blossom-black.svg`.
  [OpenAI design guidelines](https://openai.com/brand/).

The marks belong to their respective vendors; their brand terms apply. They are
not claimed to be MIT-licensed under the removed icon-library notice. The product
renders the Claude Code and Codex assets as the approved monochrome CSS masks.
ChatGPT is an additional preview reference, not an execution-provider value; a
reported GPT model never selects a ChatGPT tool badge.
